HackMatch - 黑客松现场组队与破冰微工具

1. 问题定义：解决黑客松现场选手互相不认识、社恐不敢搭讪、组队效率低的问题。面向用户：黑客松参赛选手、组织者。

2. 核心功能与流程：提供“名片生成”与“破冰匹配”两大核心闭环。用户登录 -> 生成个人技能名片（可截图分享） -> 在匹配墙点选心仪队友 -> 触发带有破冰问题的组队弹窗。

3. 技术实现：

技术栈：原生 HTML5 / CSS3 / JavaScript（无任何框架依赖，极速加载）。

运行方式：直接用浏览器双击 index.html 即可运行，或访问 Vercel 部署链接。

数据/接口：纯前端演示数据（Mock Data），无后端接口。

4. 边界与风险：

风险1：现场网络极差 -> 处理：全部代码和资源本地化，零外部依赖。

风险2：生成图片兼容性 -> 处理：放弃 html2canvas，改用原生 Canvas API 手绘，彻底规避浏览器安全限制。

风险3：用户不知道该点哪 -> 处理：增加卡片悬浮特效与按钮文案动态变化（“邀请XX组队”）。

5. 后续迭代计划：

优先级1：接入真实的云端数据库（如 Supabase），实现真实的实时组队与微信通知（代价：需要部署后端，增加维护成本）。

优先级2：增加 AI 智能匹配算法，根据技能互补度推荐队友（代价：需接入大模型 API，产生费用）。
